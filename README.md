# Dandiya Baramati

A mobile-first Baramati-only Dandiya/Garba partner finder MVP for Navratri 2026.

## Included
- Baramati-only onboarding
- 18+ confirmation
- Dandiya / Garba / Both
- Beginner / Intermediate / Advanced
- Relaxed / Medium / Fast tempo
- Baramati area preference
- Navratri Night 1–9 selection
- Festival vibe preferences
- Compatibility scoring
- Responsive mobile-first UI
- Local browser storage for the MVP

## Matching score
The demo ranks profiles using shared Navratri nights, dance-type compatibility, skill level, tempo, Baramati area and shared vibe.

## MVP limitation
This is a frontend prototype. Demo profiles are bundled in app.js. Real accounts, database storage, authentication, mutual matching, chat, reporting/blocking and verification should be added before public launch.

## Run
Open index.html in a browser or serve the folder with any static HTTP server.

## Product direction
Keep the product Baramati-only initially. Add real Baramati event/venue listings and a backend after validating local demand.
